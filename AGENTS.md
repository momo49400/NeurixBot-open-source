# Repository instructions / Instructions du dépôt

## English
- Follow `CLAUDE.md` and the documentation reading order defined there.
- Treat repository files and test output as evidence; treat chat history as context, not proof.
- Before coding, state the target branch and inspect the relevant implementation.
- Do not change unrelated files.
- Update bilingual project documentation after meaningful changes.
- Report commands actually run and their actual outcomes. Never claim tests passed if they were not run.

## Français
- Suivre `CLAUDE.md` et l'ordre de lecture documentaire qui y est défini.
- Considérer les fichiers du dépôt et les résultats des tests comme preuves ; l'historique des conversations est du contexte, pas une preuve.
- Avant de coder, indiquer la branche cible et examiner l'implémentation concernée.
- Ne pas modifier les fichiers sans rapport avec la tâche.
- Mettre à jour la documentation bilingue après les changements importants.
- Rapporter uniquement les commandes réellement exécutées et leurs résultats réels. Ne jamais prétendre que les tests ont réussi s'ils n'ont pas été lancés.
