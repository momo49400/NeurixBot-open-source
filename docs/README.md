# Documentation / Documentation

This directory is the durable, bilingual project memory for AI assistants and human contributors.
Ce dossier constitue la mémoire durable et bilingue du projet pour les assistants IA et les contributeurs.

| File / Fichier | Purpose / Rôle |
|---|---|
| `PROJECT_STATUS.md` | Verified state, active branch, working features, blockers / État vérifié, branche active, fonctions opérationnelles, blocages |
| `ARCHITECTURE.md` | Components, data flow, integrations, dependencies / Composants, flux de données, intégrations, dépendances |
| `ROADMAP.md` | Prioritized next steps / Prochaines étapes priorisées |
| `CHANGELOG.md` | Human-readable changes / Historique lisible des changements |
| `DECISIONS.md` | Durable technical/product decisions / Décisions techniques et produit durables |
| `SESSION_HANDOFF.md` | Latest session handoff and next action / Dernière transmission de session et prochaine action |

## Evidence labels / Niveaux de preuve
- **Verified / Vérifié:** confirmed in current source, tests, CI or repository metadata.
- **In progress / En cours:** implementation has started but is incomplete.
- **Planned / Prévu:** agreed direction, not implemented.
- **Blocked / Bloqué:** progress depends on an identified blocker.
- **Unknown / Inconnu:** not yet inspected or confirmed.

Do not turn a planned item into a verified feature. Date status updates in ISO format (`YYYY-MM-DD`).
Ne jamais présenter un élément prévu comme une fonctionnalité vérifiée. Dater les mises à jour au format ISO (`YYYY-MM-DD`).

## Bilingual maintenance / Maintenance bilingue
Keep French and English sections semantically equivalent. If a section is changed, update its counterpart in the same commit.
Garder les sections française et anglaise équivalentes. Toute modification d'une section doit être répercutée dans l'autre dans le même commit.
