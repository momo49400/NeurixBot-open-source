# Architecture / Architecture

## English
**Status: pending repository audit.** Do not infer architecture from the project name, roadmap or chat history.

For each component, record:
- Name and responsibility
- Source files and entry points
- Inputs, outputs and data flow
- Dependencies and external services
- Configuration and required environment variables (names only; never values)
- Error handling, security boundaries and persistence
- Tests that cover the component

## Français
**État : audit du dépôt à effectuer.** Ne pas déduire l'architecture du nom du projet, de la feuille de route ou de l'historique des conversations.

Pour chaque composant, documenter :
- Son nom et sa responsabilité
- Les fichiers sources et points d'entrée
- Les entrées, sorties et flux de données
- Les dépendances et services externes
- La configuration et les noms des variables d'environnement (jamais leurs valeurs)
- La gestion des erreurs, les limites de sécurité et la persistance
- Les tests qui couvrent le composant
