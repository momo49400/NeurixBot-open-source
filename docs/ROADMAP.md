# Roadmap / Feuille de route

Priorities describe intended work, not completed functionality.
Les priorités décrivent le travail envisagé, pas des fonctionnalités déjà terminées.

## P0 — Establish reliable context / Établir un contexte fiable
- [ ] Audit repository files, branches and recent commits / Auditer les fichiers, branches et commits récents.
- [ ] Map actual components and entry points / Cartographier les composants et points d'entrée réels.
- [ ] Identify test commands and CI status / Identifier les commandes de test et l'état de la CI.
- [ ] Replace unknown placeholders with evidence-backed facts / Remplacer les inconnues par des informations vérifiées.

## P1 — Improve maintainability / Améliorer la maintenabilité
- [ ] Document configuration and setup / Documenter la configuration et l'installation.
- [ ] Document security boundaries and failure modes / Documenter les limites de sécurité et les cas d'erreur.
- [ ] Add decision records for durable choices / Ajouter des fiches pour les décisions durables.

## P2 — Cross-assistant workflow / Flux multi-assistants
- [ ] Validate instructions with Claude Code and Codex / Valider les instructions avec Claude Code et Codex.
- [ ] Define a lightweight session handoff routine / Définir une routine légère de transmission entre sessions.
